# Diana Lash — демонстрационный концепт MiTa-X

Демо сайта мастера ресниц и бровей: светлый интерфейс, анимация логотипа, слайдер работ, карточки процедур, прайс и подготовка заявки в Telegram.

Это демонстрация дизайна и разработки MiTa-X. Проект не является заказным или проданным сайтом Diana Lash.

## Публикация

Сайт готов для GitHub Pages без установки зависимостей и сборки. Источник публикации: ветка `main`, корень `/`. Файл `.nojekyll` отключает обработку Jekyll. После включения GitHub Pages обновления ветки автоматически публикуются.

## Файлы

- `index.html` — главная страница.
- `style.css` — оформление и анимации.
- `app.js` — слайдер и заявка на запись.
- `preloader.js` — запуск и завершение прелоадера.
- `logo.html` — отдельный просмотр анимации логотипа.
- `assets/sources.json` — источники фотографий и прайса.

Фотографии и прайс взяты из публичного канала [DI_LASH](https://t.me/dianna_lash). Заявки не отправляются автоматически: посетитель открывает Telegram и подтверждает отправку сам.
